# 不孕要检查什么项目

> 更新时间：2026-09-11 (UTC+8)

不孕不育是一个复杂的医疗问题，涉及**双方多个方面的因素。为了找到不孕的原因，夫妻双方都需要进行全面的检查。以下是不孕检查的一些主要项目，涵盖了男性和女性双方。

 一、女性不孕检查项目

 1. 妇科检查

 白带常规：用于检测阴道炎症，如细菌性阴道炎、滴虫性阴道炎等。

 支原体、衣原体、淋球菌检查：这些感染可能导致不孕或流产，因此需要排除。

 2. 内分泌检查

 生殖激素六项：在月经间歇期的第2-4天测定，可以了解卵巢功能，包括促卵泡生成素、促黄体生成素、雌激素、孕激素、雄激素、催乳素等。

 甲状腺功能检查：甲状腺功能异常也可能影响怀孕，因此需要进行检测。

 3. 卵巢功能评估

 基础体温检测：通过连续监测基础体温，了解是否有正常的排卵。

 超声监测卵泡发育：通过B超直观观察卵泡的发育状况，评估卵泡能否正常排出。

 4. 输卵管通畅性检查

 输卵管造影：在月经干净后3-7天进行，通过X光或超声下造影，了解输卵管是否通畅，有无积水、粘连等问题。

 5. 免疫学检查

 对于排卵和输卵管均正常的患者，以及复发性流产的患者，建议进行免疫学检查，如抗心磷脂抗体、抗子宫内膜抗体、抗精子抗体等，明确是否存在免疫性不孕。

 6. 宫腔镜检查

 对于复发性流产、超声多次提示有内膜异常（如宫腔粘连、内膜息肉等）的患者，建议进行宫腔镜检查，必要时进行手术治疗。

 7. 腹腔镜检查

 造影提示有输卵管积水、输卵管梗阻或影像学检查提示有子宫内膜异位症、卵巢囊肿的患者，可行腹腔镜检查明确腹腔内有无粘连，生殖系统有无病变，必要时可同时进行手术治疗。

 8. 染色体检查

 对于复发性流产、原发性闭经、生殖系统畸形的患者，建议进行染色体检查，排除遗传因素导致的不孕。

 二、男性不孕检查项目

 1. 精液常规检查

 - 禁欲3-7天后进行，检查精液的量、精子的数量、活动度和形态等。

 - 可同时检查DFI（精子DNA碎片检测），了解精子质量。

 2. 精浆生化检查

 了解精浆的成分，判断有无炎症或其他异常。

 3. 微生物检查

 检查支原体、衣原体等感染情况，这些感染可能影响精子质量。

 4. 内分泌检查

 包括生殖激素、甲状腺功能等，了解内分泌系统是否正常。

 5. 遗传学检查

 如果多次精液常规提示重度的少弱精子症或DFI升高，建议完善染色体检查，排除遗传因素导致的不孕。

 6. 男科超声检查

 了解前列腺、睾丸、附睾等生殖器官的情况，判断有无异常。

 不孕检查是一个全面而复杂的过程，需要夫妻双方共同参与。通过详细的检查，可以明确不孕的原因，从而制定针对性的治疗方案。对于不孕不育的夫妇来说，保持良好的心态、积极配合医生的治疗是非常重要的。同时，也要注意调整生活方式，保持健康的生活习惯，为怀孕创造良好的条件。
